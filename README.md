# Ma boulangerie

Site vitrine de test, créé pour apprendre GitHub et le fonctionnement d'un site internet.

## Les fichiers

- `index.html` : page d'accueil
- `histoire.html` : notre histoire
- `produits.html` : nos produits
- `galerie.html` : galerie photos
- `contact.html` : adresse, téléphone et horaires
- `style.css` : l'apparence de toutes les pages

Toutes les informations (adresse, téléphone) sont fictives.
